💡 GitHub Pages Setup

To configure your board on GitHub Pages:

  1. Create a new public/private GitHub repository.
  2. Generate a GitHub Personal Access Token (classic) with repo scope.
  3. Enter your settings in the form on the left.
  4. Click Publish to GitHub Pages.
  5. Go to Repository settings → Pages → Set source to main (or your branch).
